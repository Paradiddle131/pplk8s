## What it means for the verdict

- The hard set does not move the managed ranking: the generated context (`native-context`, `native-context-bare`) leads on both sets, now above 90% here with no confident-wrong run, and its lead over Knowledge Catalog's dbt import (`native-kc`) grows on the hard questions (about 29 points, against 23 on the frozen set).
- Most of that lead is reach: Knowledge Catalog's import on the same tables (`native-kc-reach`) recovers 23 points on both sets; on the hard set what is left between it and the generated context is confident-wrong (6.2% against 0.0%, an interval below zero), not accuracy (an interval across zero).
- The verified queries add nothing measurable on the hard set either (`native-context-bare`, without them, is level), so the generated glossary and instruction over the right tables carry the arm.
- The warehouse-object arms (`native-governed`, `native-shaped`, `native-graph`) fall further behind on the hard set; `native-shaped` and `native-graph` are confidently wrong on one hard run in six or seven.
- Whether our arms change the verdict on the hard set waits on their runs: the rule cannot apply to both sets until then.
