Method, briefly

Each question is asked up to three times per setup and model, each run in a fresh session; Claude Code subagents run in another harness, one fresh subagent per question, so they are shown for comparison and never decide. A run is right when every turn carries the expected number, and confidently wrong when a number outside tolerance comes with no hedge; a blind judge model decides the turns the scoring code cannot.

Accuracy and confident-wrong are means over questions with a 95% percentile bootstrap interval over questions. Comparisons against the managed best and the floor are paired by question; an interval that includes zero is a tie. Our setups decide on a free model and Claude repeats them as a check; Google's data agents run on Gemini only. Runs that failed for infrastructure reasons are excluded, never scored.

Glossary

Setup
One way of answering: an agent, the tools and context it is given, and the tables in its reach.
Hidden-rule question
A question whose obvious SQL gives another number, because a business rule (cancelled orders, a semi-additive balance) is not visible in the table.
Covered, uncovered
Covered: a metric of the semantic layer answers it. Uncovered: no metric does, though SQL over the tables can.
Confident-wrong
A wrong number stated with no hedge, the failure a business user feels. A lower rate counts only when accuracy ties.
Decides, check
Our setups run on a free model, which decides; Claude Haiku, Sonnet and Opus repeat them as a check on whether a gap is the model's.
Pending
A setup that has run on Claude only, the check; it enters headlines and the winners once its deciding run exists.
95% interval
A percentile bootstrap over questions: the range the mean would likely fall in on another draw of questions like these.
Partial pass
A pass with fewer questions than the set or fewer than three runs per question, tagged on its row.
Managed best
The most accurate of Google's managed setups, the bar each of ours is paired against.
The floor
Google's data agent over the tables alone, with no context: every gain is read against it.
