Method, briefly

Glossary

Setup
One way of answering: an agent, the tools and context it is given, and the tables in its reach. The eval code calls it an arm.
Hidden-rule question
A question whose obvious SQL gives another number, because a business rule (cancelled orders, a semi-additive balance) is not visible in the table. The eval calls it a trap.
Covered, uncovered
Covered: a metric of the semantic layer answers it. Uncovered: no metric does, though SQL over the tables can.
Confident-wrong
A wrong number stated with no hedge, the failure a business user feels. The rule credits a lower rate only when accuracy ties.
Decides, check
Our setups run on a free model, which decides; Claude Haiku, Sonnet and Opus repeat them as a check on whether a gap is the model's.
95% interval
A percentile bootstrap over cases: the range the mean would likely fall in on another draw of questions like these.
Partial pass
A pass still under way: fewer cases than the set, or fewer than three runs per case. Marked wherever it appears.
Managed best
The most accurate setup on Google's managed rungs (1 and 2), the bar each of ours is paired against.
