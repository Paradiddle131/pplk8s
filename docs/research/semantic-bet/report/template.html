Method, briefly

Runs
Each question is asked up to three times per setup and model, each run in a fresh session.
Scoring
A run is right when every turn carries the expected number, and confidently wrong when a number outside tolerance comes with no hedge; a blind judge model decides the turns the scoring code cannot.
Exclusions
Runs that failed for infrastructure reasons are excluded, never scored.
Intervals
Accuracy and confident-wrong are means over questions with a 95% percentile bootstrap interval over questions.
Comparisons
Comparisons against the managed best and the floor are paired by question; an interval that includes zero is a tie.
Models
Our setups decide on a free model and Claude repeats them as a check; Google's data agents run on Gemini only.
Claude Code
Claude Code is another agent harness, so its rows are shown for comparison and never decide. It runs headless, one fresh session a run, with only its setup's tools and no shell, file or web tool, and every transcript is checked for that.
