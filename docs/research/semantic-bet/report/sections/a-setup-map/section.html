What each setup is

Every setup on one map. Each part is drawn once, where it runs; a setup is a path through the parts it uses: who asks, on which model, through which tools, with what context, over which tables. Google's data agents write their own SQL from whatever context they hold. Our agent on MetricFlow never writes SQL: it lists the metrics, reads one metric's definition and dimensions, and asks MetricFlow to compute; MetricFlow writes the SQL.

Hover or tap a setup, a rung, or any part of the map; tap again to let go.
